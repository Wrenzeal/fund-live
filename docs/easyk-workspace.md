# 可保存的公式研究工作台

入口：`/research` → “自定义公式工作区”。本页沿用 FundLive 的市场研究接口，无需登录、数据库或额外付费数据账户，可随 `web/` 部署到 Vercel。

## 本次补齐

对照 EasyK.work 公开介绍的公式输入、曲线对齐、组合事件与保存研究图，新增：

- A/B/C 三个数据变量：选择大盘、半导体、通信、人工智能、重点个股，或红利低波、电力、黄金、短融等配置观察标的。字段可选开盘、最高、最低、收盘、成交量。
- 最多三条公式曲线；公式在服务端计算，修改后点击计算即可更新。
- 最多三个事件条件，支持大于、小于、向上穿越、向下穿越，以及全部满足/任一满足。
- 曲线原始值或共同日期基期100显示，图中标出事件触发点；显示样本、方向命中、费用后价格收益与回撤上界。
- 命名方案在当前浏览器保存、加载、删除，支持方案 JSON 导入/导出。不会跨设备同步，清除浏览器数据会丢失本地方案，导出可用于备份。
- 开启持续跟踪后按交易状态定期重新计算已经提交的方案；编辑草稿不会改变正在跟踪的规则。
- 板块净流入/净流出排名、来源时间与异常状态，帮助把技术条件与资金观察放在同页。

这是基于公开数据的独立实现。EasyK 的付费因子包、专属宏观数据库、云端多面板、付费订阅和通知服务没有复制或接入；公开源没有提供的数据不补造。

## 示例

来源 A 选择半导体 ETF 收盘价，B 选择科创50收盘价：

```
A / MA(A,20) * 100
ROC(A,5) - ROC(B,5)
```

第一条表示价格相对20期均线的位置，100为均线参考水平；第二条表示5期涨幅差，单位为百分点。不同单位的原始曲线不能只凭高度比较。

组合事件可设为 `A` 向上穿越 `MA(A,5)`，同时 `B` 大于 `MA(B,5)`。这是一条可以回看和跟踪的观察规则，并非买入保证。事件使用原始表达式计算，切换图表归一化不会改变事件。

## 公式函数

支持 `+ - * /`、负号、括号与以下函数，函数名大写。`X`可以是变量或另一个表达式，`N`须为1—200的整数字面量（`REF`允许0）。

| 函数 | 含义 |
| --- | --- |
| `MA(X,N)` | N期简单均值 |
| `EMA(X,N)` | 首个完整N期均值初始化的指数平滑 |
| `RSI(X,N)` | N期Wilder相对强弱指标 |
| `REF(X,N)` | N期前的值，不接受负数或未来引用 |
| `ROC(X,N)` | N期变化百分比 |
| `STD(X,N)` | N期总体标准差 |
| `MIN(X,N)` / `MAX(X,N)` | N期滚动最小值 / 最大值 |
| `ABS(X)` | 绝对值 |

预热不足、缺值或除零返回空值；不以0代替。归一化需要共同日期上每条曲线存在大于零的有限基值，含负值的相对强弱公式不宜解释为资产收益。

## API

`POST /api/v1/market/workspace`，请求为命名方案、来源、曲线、事件条件、研究标的、持有期、往返费用和展示区间。仅接受白名单标的；公式只允许受限算术和明确支持的时间序列函数，不执行 JavaScript。请求正文、公式长度、层级、来源和曲线数量均有上限。

## 数据和历史统计

只使用已完成日线；不把盘中未完成的反弹当成收盘触发。ETF使用同源前复权日线，指数使用原始日线，不拼接未复权实时价格形成伪信号。多个来源只对齐共同日期，不填补缺失行情；指标周期按对齐后的共同观测期计算，因此遇到停牌或日期缺失时不等同于自然日。

连续阈值条件只在已知不满足转为满足时记录事件；组合满足且出现新的有效穿越时记录新事件，即使另一条件已持续满足。穿越不跨缺失的交易日。历史研究按信号后下一交易日收盘进入参考、固定交易日持有，排除重叠样本；尚未完成的样本单独统计。向下事件表示规避下跌的方向检验，不模拟做空。研究样本有限，历史正确率不代表未来获利概率。

公开源超时会保留实例的上次成功数据并显示过期；首次请求失败会显示不可用。实例缓存不持久、不跨Vercel实例共享。

板块资金来自数据商按成交分类估算，取净流入和净流出排名各前50项，并非完整板块列表。板块可能重叠，不能相加，不能等同ETF申赎或机构真实持仓变化。
