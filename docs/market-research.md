# 市场研究

在顶栏点击“研究”，或打开 `/research`。本页无需登录，不依赖 Go 服务器、PostgreSQL、DragonFly 或 Lean Worker。研究数据接口是 Next.js Node.js Route Handler，可随前端一起部署到 Vercel。

## Vercel

部署现有 `web/` 项目即可发布 `/research` 及其同源 `/api/v1/market/research/*` 接口。研究接口由 Vercel 的服务端函数获取公开行情和计算指标，不调用 `BACKEND_URL`，无需额外密钥。浏览器始终使用同源地址。

原有账号、持仓、基金搜索等功能仍使用 Go 后端和数据库；后端停机时这些功能不可用，研究页仍可运行。Vercel 的函数实例缓存不共享、不持久，冷启动和重新部署会重新获取数据。公开数据源可能限制境外云节点，部署后应检查各来源是否可用；失败会显示不可用或该实例保留的旧数据，不能保证每次都有历史缓存。

## 本机运行（Windows）

安装 Node.js，在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

默认前端 `http://127.0.0.1:3100/research`。脚本必要时安装锁文件中的前端依赖，使用 Webpack 开发模式，日志写到忽略目录 `logs/`。停止：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-local.ps1
```

端口冲突可使用 `-WebPort 3101`。需要完整本机账号、持仓功能时，安装 Go 并增加 `-WithBackend`，可用 `-ApiPort 8082` 指定端口。该选项以内存模式启动 Go，账号和持仓会随后端退出清空；已有生产持仓仍使用原 PostgreSQL 启动方式。脚本不导入个人金额，不连接生产数据库。前端绑定 127.0.0.1；可选 Go 服务沿用监听所有网卡的行为。

## 内容

- 大盘指数、通信/CPO、半导体、AI ETF 与重点个股；显示上游行情时间。
- 日线、分时、共同交易日起点归一化对比；MA5/20/60、RSI14 与前日低点条件。
- 沪深涨跌家数和成交额（不含北交所）。新闻标题来自东方财富公开快讯，可打开原文；标题本身不是经独立核实的事实。
- 四条公开可解释规则的历史事件统计：20日均线上穿/下穿、RSI14回升穿过30、跌破前日低点。

## 公式、事件与方案

同页“自定义公式工作区”可编辑 A/B/C 来源、算术与技术指标曲线，组合阈值和穿越条件，显示历史触发与样本结果，并在浏览器保存命名方案或导入/导出 JSON。板块资金区独立读取资金排名，失败不影响行情与公式。具体操作和边界见 [公式研究工作台](easyk-workspace.md)。

## 数据与统计口径

腾讯公开行情提供快照、分时和近期前复权日线，东方财富提供市场宽度和公开快讯。各源独立缓存、限时请求；接口失败可显示本服务实例上次成功内容并标为陈旧，首次失败会明确显示不可用。公开源可能延迟或调整接口，无法保证交易所级实时性，也不包含 EasyK 的付费因子。

技术指标基于日线；盘中当日日线是暂定数据，可能落后于报价快照，不混合未复权报价与前复权历史价。历史研究排除尚未完成的当日日线。只使用当时及之前价格计算触发条件，以触发后下个交易日收盘为进入参考、固定交易日退出，避免重复持有的重叠样本。向下规则显示规避下跌的方向命中，不代表能做空或赚到对应金额。

设置的费用是一次完整交易合计基点：10基点为0.10个百分点。它不能覆盖所有基金的持有期赎回费、申购费或实际滑点。统计范围为接口返回的近期交易日，样本少会提示，不使用精选案例推断未来胜率。回撤显示单次事件期间从此前高点到低点的正数损失幅度。日线无法确定同日高低点先后，按先高后低计算，是可能高估损失的回撤上界估计，不是完整策略账户回撤。

ETF和个股不是场外基金净值。基金实际买卖受申请截止时间、份额确认、费用、持仓变化及跟踪误差影响。此页提供观察和研究，不自动下单，也不提供保证收益的买卖指令。
